● เชื่อมสมองสำรองเข้ากับ GitHub

กรอกครั้งเดียวต่อเครื่อง หลังจากนี้ทุกอุปกรณ์ที่เชื่อมด้วยข้อมูลเดียวกัน จะเห็นของเหมือนกันหมด

ถ้ายังไม่มี repo นี้ ให้สร้างก่อน (ดูวิธีด้านล่าง)
token เก็บอยู่ในเครื่องนี้เท่านั้น ไม่ถูกส่งไปที่อื่นนอกจาก GitHub
ยังไม่มี repo หรือ token?
1. สร้าง repo ใหม่ชื่อ braindump-data ตั้งเป็น Private
2. Settings → Developer settings → Personal access tokens → Fine-grained tokens
3. ให้สิทธิ์เฉพาะ repo braindump-data → Permissions → Contents: Read and write
4. ก๊อป token มาวางช่องด้านบน (มีคู่มือละเอียดในไฟล์ README.md)
